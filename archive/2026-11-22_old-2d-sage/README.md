# Old 2D Sage (archived 2026-11-22)

The articulated SVG "walking" Sage (sage-sprite.js + its CSS) was the 2D fallback when the 3D courtyard
could not start. It no longer matches the locked v06 look, and visitors whose browser fell back to it saw an
old Sage walking around instead of the Webverse. It is kept here for history and is not loaded by any page.
If WebGL is unavailable, the pages now show a still of the approved v06 reference instead.
