# Security policy

Copyright (c) 2026 Saint Chevalier / Clover Kingdom. All rights reserved.

This is a public Clover Kingdom repository. Please help us keep it safe.

## How to report a problem

Do not post secrets, tokens, passwords, or private personal data in a public issue, pull request, or discussion.

Use GitHub's private vulnerability reporting on this repository if it is available, or contact the Clover Kingdom through the public site at https://cloverkingdom.net.

Give us enough detail to find and fix the issue. Do not include live secret values in the report if a redacted description is enough.

## What belongs here

Public files in this repository should not contain keys, tokens, passwords, private machine paths, or unreleased private plans.

We will take a good-faith report seriously and will not treat a careful, private disclosure as an invitation to debate it in public first.
